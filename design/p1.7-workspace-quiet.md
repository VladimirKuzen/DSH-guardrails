# P1.7 工作区静默（workspaceQuiet）

**状态**：1.4.0 已实现，单元测试与插件冒烟测试通过；live 验收待重启后执行。
**动机**：审计显示 R2 的弹卡绝大多数来自“清理自己工作区里的临时文件”。这类操作没有不可逆风险，
却和删除用户目录共用同一张卡，长期会造成告警疲劳——真正危险的那次更容易被手滑放行。

## 目标与非目标

- 目标：把“单个、非递归、无通配符、位于白名单目录下的删除或移动”从弹卡降为静默放行。
- 非目标：不做“工作区内一律放行”。删除 `.git`、仓库根、带 `-Recurse` 的清理仍会弹卡。
- 非目标：不改变 R1（DSH 自身目录）、R3（密钥）、critical（磁盘/启动/系统目录）的任何行为。

## 配置

```json
"destructive": {
  "mode": "ask",
  "workspaceQuiet": {
    "enabled": false,
    "roots": ["D:\\work\\guardrails"],
    "paths": ["_scratch/", "build/", "dist/"],
    "alwaysAsk": [".git", ".", ".."]
  }
}
```

- `roots` 必须是绝对路径（盘符或 UNC），至少两级，拒绝盘符根、UNC 共享根与含 `..` 的值。
- `paths` 只接受单段名，拒绝路径分隔符、通配符、`.` 与 `..`；`_scratch/` 与 `_scratch` 等价。
- `alwaysAsk` 里的段名一票否决（默认 `.git`、`.`、`..`）。

## 判定顺序（lib/rules/quiet.js）

1. `enabled` 为真；
2. 工具是 shell；
3. 命令非空；
4. `splitStatements` 恰好一条语句；
5. 不含 `-Recurse`（或 `rd/rmdir/del/erase /s`）；
6. target 不含通配符 `* ? [`；
7. target 非空且不是未解析变量；
8. facts.kind 为 `delete` 或 `move`；
9. `count === 1`；
10. `roots` / `paths` 合法（否则 `config-invalid`）；
11. 若 cwd 已知且不在 `roots` 下 → `cwd-mismatch`（quiet 关闭并记审计）；cwd 未知则跳过；
12. target 在某个 root 之下，且不等于该 root；
13. target 的首段等于某个 `paths` 项，且不等于该目录本身；
14. target 的任何一段都不在 `alwaysAsk` 里。

全部命中 → `{ quiet: true, reason: 'eligible' }`；否则返回原因字符串，
`index.js` 只在 `reason === 'eligible'` 时把 verdict 改为 `{ mode: 'allow', quiet: 'workspace' }`。

## 审计

- v2：写 `allowed` 事件，带 `quiet: "workspace"`、payload、`cwd`/`cwdSource`。
- v1：写 `decision: "allowed"` 与 `quiet: "workspace"`。
- `config-invalid` / `cwd-mismatch` 每进程只写一条，且不阻断工具调用。

## 已知边界

- 只看命令文本里的目标，不做文件系统确认：目标不存在也会静默放行（随后命令自身报错）。
- 通过管道拼出来的目标（`Get-ChildItem … | Remove-Item`）不静态识别，落回 ask。
- 变量拼接（`$p = "…"; Remove-Item $p`）落回 ask。
- 仅覆盖 shell 工具；`file` 类写工具不经过这里。

## 验收（重启后）

| # | 操作 | 期望 |
|---|---|---|
| 1 | `_scratch` 下单个文件 `Remove-Item -Force` | 无卡，审计一条 `allowed` |
| 2 | 同上但带 `-Recurse` | 弹卡 |
| 3 | 工作区根下的普通文件删除 | 弹卡（不在 `paths` 下层） |
| 4 | `.git` 下文件删除 | 弹卡（alwaysAsk） |
| 5 | `workspaceQuiet.enabled: false` | 弹卡 |
| 6 | 同一会话里 `roots` 改成别的目录 | quiet 关闭，审计 `config-invalid` |
| 7 | .dsh 写入 / 密钥 / 系统目录 | 与以前完全一致 |
